# Harmony Architect

Создай главную страницу персонального сайта нейропсихолога Tatiana Boyraz.

ВАЖНО:
Это не SaaS-сайт, не медицинский шаблон и не корпоративный сайт.
Мне нужен премиальный персональный бренд нейропсихолога.

Основной визуальный референс — предоставленный мной макет сайта и логотип Tatiana Boyraz.

НЕ придумывай новый визуальный стиль.
НЕ используй стандартный стиль Lovable.
НЕ используй синий медицинский цвет.
НЕ используй белый фон.
